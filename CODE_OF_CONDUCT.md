# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Standards

We expect contributors to act with professionalism and good faith. Specifically:

- Be respectful in code review and issue discussion
- Assume good intent; ask clarifying questions before escalating
- Critique ideas, not people
- Accept constructive feedback gracefully
- Focus on what is best for the project and the community

## Scope

This applies to all project spaces: the GitHub repository (issues, PRs, discussions), any chat channels, and any public events where contributors represent the project.

## Reporting

If you observe behavior that conflicts with the standards above, report it privately to the maintainers:

**conduct@oak.dev** (placeholder - maintainers should update with a real contact)

Reports will be reviewed promptly and confidentially. Maintainers commit to acting fairly on legitimate reports.

## Enforcement

Maintainers may, at their discretion:
- Issue a private warning
- Issue a public warning
- Temporarily restrict a contributor from project spaces
- Permanently restrict a contributor from project spaces

Actions are proportional to the issue. Patterns of behavior are considered as a whole, not just individual incidents.
